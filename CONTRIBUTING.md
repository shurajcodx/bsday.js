# Contributing to bsday.js

First off, thank you for considering contributing to `bsday.js`! It's people like you that make it such a great tool.

## Code of Conduct

Help us keep `bsday.js` open and inclusive. Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## How Can I Contribute?

### Reporting Bugs

- **Check for existing issues**: Before you open a new issue, please search the [issues tracker](https://github.com/shurajcodx/bsday.js/issues) to see if the bug has already been reported.
- **Provide a reproduction**: If you find a bug, please provide a minimal reproduction if possible.

### Suggesting Enhancements

- **Open an issue**: Explain the feature you'd like to see and why it would be useful.

### Pull Requests

1.  **Fork the repository**.
2.  **Create a branch** for your changes.
3.  **Install dependencies**: `pnpm install`
4.  **Make your changes**.
5.  **Run tests**: `pnpm test`
6.  **Ensure code style**: `pnpm run lint` and `pnpm run format`
7.  **Submit a pull request**.

## Development Setup

This project uses `pnpm` workspaces.

```bash
# Install dependencies
pnpm install

# Build all packages
pnpm run build

# Run tests
pnpm run test

# Check types
pnpm run typecheck
```
